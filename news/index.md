# Registro de cambios

## cmfr 0.0.0.9000

- Reinicio del repositorio como cliente R pequeño para datos
  estadísticos públicos de la CMF, con foco inicial en BEST+.

  dependencias mínimas.
- La documentación del sitio se separa del README del repositorio
  mediante `pkgdown/index.md`.
